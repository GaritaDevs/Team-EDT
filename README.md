## Team PROJECT - Web Service Weather Project

## Overview 

With the increasing unpredictability of local weather patterns and severe storm events, residents frequently find themselves checking multiple fragmented sources—local news sites, radar apps, government meteorological portals, and social media feeds—just to get an accurate, localized forecast. 
Currently, comprehensive weather data is scattered across complex meteorological interfaces or ad-supported apps cluttered with extraneous information. 
Our web service provides a streamlined, single-input platform where users can simply enter their zip code to instantly access localized, real-time weather conditions and forecasts.
